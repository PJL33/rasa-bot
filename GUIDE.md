# Mode d’emploi pour la personne qui configure l’assistant

- Associer chaque question aux formulations similaires utilisées par les clientes (ex. « où est mon colis ? », « suivi bloqué », « pas reçu »).
- Répondre dans la langue de la cliente lorsque possible, sans changer le sens de la réponse approuvée.
- Ne jamais inventer un prix, un stock, un délai, un diagnostic de peau ou une décision de remboursement.
- Pour toute commande précise, demander le nom complet et le numéro de commande, sans demander de données bancaires sensibles.
- Transférer à une personne les réactions importantes, litiges de paiement, demandes de remboursement, colis perdus, erreurs complexes, grossesse/allaitement et demandes médicales.

| **Note importante :** les prix et stocks peuvent changer. Le panier et la fiche produit sur pepites-zone2.com restent la référence au moment de l’achat. |

# 2. Gammes et produits

| **Q7. C’est quoi le Kit Glowelle ?** |
| --- |
| **Réponse :** Le Kit Glowelle est une routine visage composée de trois essentiels : le savon visage, la lotion Glowelle et la crème hydratante visage Glowelle. |

| **Q8. À quoi sert Glowelle ?** |
| --- |
| **Réponse :** Glowelle aide à raviver l’éclat, à améliorer l’apparence des taches et à rendre le teint plus uniforme. Les résultats varient selon la peau, la régularité de la routine et la protection solaire. |

| **Q9. C’est quoi la Gamme Glowelle complète ?** |
| --- |
| **Réponse :** La Gamme Glowelle complète réunit six soins : trois produits pour le visage et trois pour le corps. Elle comprend la routine visage ainsi que le savon, le lait et l’huile pour le corps. |

| **Q10. C’est quoi la gamme corporelle Glowelle ?** |
| --- |
| **Réponse :** La gamme corporelle Glowelle comprend un savon, un lait et une huile pour le corps. Elle est conçue pour nettoyer, nourrir la peau et favoriser un aspect plus lumineux et uniforme. |

| **Q11. C’est quoi le Kit Melanight ?** |
| --- |
| **Réponse :** Le Kit Melanight est conçu pour les peaux foncées ou les personnes qui souhaitent améliorer l’apparence des boutons et des taches tout en uniformisant et illuminant leur teint naturel, sans rechercher un effet éclaircissant. |

| **Q12. Quelle est la différence entre Glowelle et Melanight ?** |
| --- |
| **Réponse :** Glowelle vise surtout l’éclat et l’apparence des taches et du teint irrégulier. Melanight respecte la couleur naturelle du teint et convient aux personnes qui ne souhaitent pas éclaircir leur peau. Si vous hésitez, décrivez-nous votre objectif et votre type de peau. |

| **Q13. Quel produit choisir si je ne veux pas éclaircir mon teint ?** |
| --- |
| **Réponse :** Nous vous recommandons de regarder le Kit Melanight, conçu pour uniformiser et illuminer le teint naturel sans objectif éclaircissant. |

| **Q14. Quel produit choisir pour mes taches ?** |
| --- |
| **Réponse :** Glowelle, Melanight ou la crème anti-taches peuvent être envisagés selon votre teint, votre sensibilité et la routine que vous utilisez déjà. Envoyez une photo nette, sans filtre et en lumière naturelle, ainsi qu’une description de votre peau, pour une orientation plus précise. |

| **Q15. La lotion Glowelle fait quoi ?** |
| --- |
| **Réponse :** La lotion Glowelle s’utilise dans la routine du soir. Elle aide à raviver l’éclat et à améliorer progressivement l’apparence du teint irrégulier et des taches. |

| **Q16. La crème visage Glowelle fait quoi ?** |

# 3. Mode d’emploi

| **Q22. Comment utiliser le Kit Glowelle le matin ?** |
| --- |
| **Réponse :** Le matin : nettoyez délicatement le visage avec le savon, appliquez la crème hydratante, puis terminez avec une protection solaire SPF 50. N’utilisez pas la lotion Glowelle le matin. |

| **Q23. Comment utiliser le Kit Glowelle le soir ?** |
| --- |
| **Réponse :** Le soir : nettoyez le visage avec le savon, séchez sans frotter, appliquez la lotion Glowelle, puis la crème hydratante. Évitez le contour des yeux et suivez aussi les indications de l’étiquette. |

| **Q24. Est-ce que je peux utiliser la lotion Glowelle le matin ?** |
| --- |
| **Réponse :** Non. La lotion Glowelle est réservée à la routine du soir. Le matin, hydratez votre peau et appliquez une protection solaire SPF 50. |

| **Q25. Dois-je mettre une crème solaire ?** |
| --- |
| **Réponse :** Oui. Une protection solaire SPF 50 chaque matin est essentielle, surtout lorsque vous travaillez sur les taches et l’uniformité du teint. Réappliquez-la selon les indications du fabricant. |

| **Q26. Je colle le savon directement sur mon visage ?** |
| --- |
| **Réponse :** Il est préférable de faire mousser le savon dans les mains propres, puis d’appliquer la mousse délicatement sur le visage. Évitez de frotter directement la barre sur la peau. |

| **Q27. Combien de fois par jour utiliser le savon ?** |
| --- |
| **Réponse :** Suivez d’abord l’étiquette du produit. En général, commencez doucement et observez votre peau. Si elle devient sèche ou irritée, réduisez la fréquence et contactez l’équipe. |

| **Q28. Comment utiliser la gamme corporelle ?** |
| --- |
| **Réponse :** Utilisez le savon sous la douche, puis appliquez le lait sur la peau propre. L’huile peut être utilisée ensuite pour aider à retenir l’hydratation. Suivez les indications inscrites sur chaque produit. |

| **Q29. Puis-je mélanger vos produits avec une autre marque ?** |
| --- |
| **Réponse :** Pour limiter le risque d’irritation, évitez de superposer plusieurs actifs puissants sans conseil professionnel. Envoyez-nous les noms ou des photos des produits que vous utilisez déjà afin que nous puissions vous orienter. |

| **Q30. Puis-je utiliser les produits pendant un traitement dermatologique ?** |
| --- |
| **Réponse :** Demandez d’abord l’avis de votre dermatologue ou pharmacien. Ne combinez pas un traitement prescrit avec de nouveaux produits actifs sans leur accord. |

| **Q31. Puis-je utiliser les produits si je suis enceinte ou j’allaite ?** |
| --- |
| **Réponse :** Avant utilisation, faites vérifier la liste complète des ingrédients par votre médecin ou pharmacien. L’assistant virtuel ne doit pas confirmer qu’un produit est sécuritaire pendant la grossesse ou l’allaitement. |

# 4. Résultats, réactions et précautions

| **Q32. Au bout de combien de temps vais-je voir des résultats ?** |
| --- |
| **Réponse :** Chaque peau avance à son rythme. Certaines clientes remarquent une évolution rapidement, tandis que d’autres ont besoin de plusieurs semaines et de plus d’une boîte. La patience, la régularité et la protection solaire sont essentielles; aucun délai précis ne peut être garanti. |

| **Q33. J’ai terminé une boîte sans résultat. Que faire ?** |
| --- |
| **Réponse :** Nous comprenons votre déception 🤍 Chaque peau réagit différemment. Vérifiez que la routine est utilisée correctement et régulièrement, avec un SPF 50 le matin. Envoyez-nous aussi une photo avant/après sans filtre et la liste des autres produits utilisés pour que l’équipe puisse vous guider. |

| **Q34. Est-ce normal d’avoir de petits boutons au début ?** |
| --- |
| **Réponse :** Une peau peut réagir lorsqu’une nouvelle routine est introduite, mais il ne faut pas considérer automatiquement toute poussée comme une purge. Si les boutons sont nombreux, douloureux, accompagnés de brûlure, d’enflure ou de fortes démangeaisons, arrêtez le produit et consultez un professionnel de santé. |

| **Q35. Ma peau brûle ou devient très irritée. Que faire ?** |
| --- |
| **Réponse :** Arrêtez immédiatement l’utilisation, rincez doucement la zone et n’ajoutez aucun autre produit actif. En cas d’enflure importante, de difficulté à respirer ou de réaction sévère, obtenez des soins urgents. Pour une irritation persistante, consultez un professionnel de santé et contactez-nous avec des photos. |

| **Q36. Dois-je faire un test avant d’utiliser le produit ?** |
| --- |
| **Réponse :** Oui. Faites un test sur une petite zone de peau et attendez 24 à 48 heures avant une utilisation plus large. N’utilisez pas le produit si une réaction importante apparaît. |

| **Q37. Est-ce que les résultats sont garantis ?** |
| --- |
| **Réponse :** Non. Les témoignages reflètent l’expérience personnelle de certaines clientes, mais chaque peau est différente. Pépite-Zone ne peut pas garantir un résultat identique ni un délai précis. |

| **Q38. Vos produits traitent-ils une maladie de peau ?** |
| --- |
| **Réponse :** Nos produits sont des soins cosmétiques et ne remplacent pas un diagnostic ou un traitement médical. Pour une affection persistante, douloureuse ou sévère, consultez un dermatologue ou un autre professionnel de santé. |

| **Q39. Puis-je envoyer une photo de ma peau ?** |
| --- |
| **Réponse :** Oui. Envoyez une photo nette, sans filtre, prise en lumière naturelle. Ajoutez votre objectif, votre type de peau, les produits déjà utilisés et toute sensibilité connue. Une photo ne remplace toutefois pas un diagnostic médical. |

| **Q40. Puis-je utiliser les produits sur une peau blessée ?** |
| --- |
| **Réponse :** Non. N’appliquez pas les produits sur une plaie, une peau fortement irritée ou une zone infectée. Attendez la guérison ou demandez conseil à un professionnel de santé. |

# Quand l’assistant doit transférer la conversation

**Santé / sécurité —** Brûlure, enflure, réaction sévère, douleur, infection, grossesse/allaitement, traitement médical ou demande de diagnostic.

**Commande —** Colis déclaré perdu, article manquant ou endommagé, livraison indiquée comme livrée mais non reçue, adresse erronée après expédition.

**Paiement —** Double débit, remboursement, contestation, fraude présumée ou statut incohérent.

**Commercial —** Prix de gros, marque privée, revendeur, influenceuse ou partenariat.

**Information incertaine —** Toute question dont la réponse n’est pas dans cette base ou dont l’information dépend d’un stock, d’un prix ou d’une politique actuelle.

# Message de transfert recommandé

| Merci pour ces informations 🤍 Votre demande nécessite une vérification par notre équipe. Veuillez nous laisser votre nom complet, votre numéro de commande s’il y en a un, ainsi qu’un résumé du problème. Un membre de Pépite-Zone prendra le relais. |
| --- |

# Champs à confirmer avant la mise en ligne

- Politique officielle et délai maximal pour signaler un article manquant ou endommagé.
- Conditions exactes de retour, d’échange, d’annulation et de remboursement.
- Délais actuels de préparation avant remise au transporteur.
- Heures officielles du service client et délai moyen de réponse.
- Tarifs, quantités minimales et territoires autorisés pour la vente en gros ou la marque privée.
